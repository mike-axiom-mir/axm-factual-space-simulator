# Source Pinning v0.13.0

The blueprint is organized from official NASA primary sources covering:

- spacecraft subsystem decomposition;
- systems engineering and interfaces;
- human-system standards;
- crew training;
- ECLSS;
- power and propulsion lineage;
- thermal management;
- radiation;
- MMOD;
- communications;
- GNC;
- reliability, maintainability, FMECA, and fault response;
- deep-space interoperability.

Source URLs and roles are stored in `data/source_registry.json`.

A source describes real systems or standards. It does not certify the assembled fictional AXM ship. All unsourced integrated design numbers remain assumptions or unknowns.
