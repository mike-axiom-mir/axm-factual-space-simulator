# Immutable Four-Root Crew Core v1

## Canonical roots

1. **Truth / Source Truth**
2. **Continuity / No-Loss**
3. **Agency / No Takeover**
4. **Wisdom over Speed**

Kernel ID: `axm.roots.main-four.v1`

## Mainline rule

The default expedition crew is permanently bound to these roots.

No crew seat, human commander, AI commander, vote, model update, efficiency score, renderer, save migration, or autonomous routine can change, reorder, disable, outvote, or silently bypass them.

## Perspective rather than guard

The roots are not merely a prohibition checked after an optimizer has chosen an action.

They determine:

1. which facts and uncertainties enter reasoning;
2. which losses must be preserved or explicitly authorized;
3. whose agency and authority must be respected;
4. which options remain wise after long-term consequences;
5. only then, which eligible option is efficient.

## Evolution

Knowledge, derived principles, practices, strategies, roles, tools, and communication may evolve.

The roots do not.

A changed root set is a different explicitly labelled system. It may not masquerade as the mainline crew or silently migrate an existing expedition.
