- public player files contain no private packet, selected theory pair, selected anomaly/life IDs, or resolution secret;
- private packet tampering breaks the pre-play commitment;
- event tampering breaks replay verification;
- wrong private packet fails closed;
- changing entropy can change a measurement without changing hidden starting truth;
- same private packet, action, state, and entropy replay exactly;
- public evidence advances by at most one stage per action;
- a null result constrains only the tested channel.

Not claimed:

- secure multi-party hardware isolation;
- protection from a user who deliberately opens the full steward archive;
- empirical probabilities for hidden origin classes;
- complete biochemical or cosmological simulation;
- autonomous scientific discovery beyond the registered models.
