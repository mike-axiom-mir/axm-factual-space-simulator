# Default Crew Root Binding v1

The First Expedition Crew binds every command position and deterministic station to `axm.roots.main-four.v1`.

The binding covers:

- deterministic autonomous mode;
- AI command;
- human command;
- collaborative command;
- action-menu assessment;
- away-from-deck crew autonomy;
- command recall;
- derived crew principles;
- future skill and strategy growth.

Command authority may choose among valid actions. It does not include authority to rewrite the roots.

Future crews may add identities, cultures, roles, embodiments, room arrangements, or derived principles. Safe mainline crews must retain the root binding. Any root-changed research branch must be explicitly labelled experimental and cannot silently replace existing saves.
