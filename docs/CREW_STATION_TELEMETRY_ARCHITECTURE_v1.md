# Crew Station Telemetry Architecture v1

The same authoritative ship state now produces 6 task-focused station views and 78 registered telemetry metrics.

The Command Duet contains commander-left, shared-center and AI-collaborator-right surfaces. Every metric includes value, unit, truth type, status, trend, quality, meaning, plain-language help, role relevance and influence links. Unknown is never displayed as zero.

Roles receive different trained perspectives, not different truths.
