# Source-Neutral Exploration Functions to Real Engineering

The public runtime uses no franchise-specific names.

Exploration fiction may suggest broad functions such as a central power architecture, integrated bridge command, multi-domain sensors, onboard fabrication, immersive simulation, docking, protection, and sustained crew loading. The simulator translates only those functions into current or explicitly hypothetical engineering categories.

No fictional label authorizes a physical capability.

The authoritative map is stored in `data/exploration_function_map.json` and includes:

- real capability identifiers;
- partial analogs;
- unavailable claims;
- explicit status notes;
- a rule that the visualization layer has no physics authority.

Unavailable capabilities include faster-than-light travel, matter teleportation, inertia cancellation, static artificial gravity without acceleration or rotation, force fields, arbitrary matter creation, and simulated solid matter.
