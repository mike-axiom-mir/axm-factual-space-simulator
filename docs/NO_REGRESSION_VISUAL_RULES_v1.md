# No-Regression Visual Rules v1

A candidate bridge build fails review when any of the following is true:

1. The main experience resembles a generic website more than a vessel interior.
2. The universe view is demoted below the first archetype's minimum share.
3. The player and collaborator command positions disappear.
4. Active crew stations have no visible spatial representation.
5. Panels become unrelated cards outside the room.
6. Station focus erases all room context.
7. Paint-level rendering can no longer express the room.
8. A new skin changes station identity or room function.
9. A historical reconstruction changes recorded events.
10. A future ship is implemented by mutating an old pinned archetype rather than registering a new one.

## Review rule

Visual quality never compensates for a failed room grammar.

A beautiful dashboard is still a regression.
A crude bridge with preserved spatial identity is acceptable.
