# Personal Quarters and Items v1

The primary explorer and AI collaborator each have a persistent personal room.

Items may be:

- found;
- fabricated;
- gifted;
- reconstructed;
- catalog replicas.

Items retain immutable provenance and status:

- decorative;
- experimental;
- validated tool;
- evidence object;
- unresolved object.

Room customization changes placement and appearance, not scientific truth.

A reconstructed artifact is not the original. An unresolved object remains unresolved. A fabricated object becomes a usable tool only after explicit capability validation.
