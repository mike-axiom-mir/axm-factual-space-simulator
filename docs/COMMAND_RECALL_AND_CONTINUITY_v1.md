# Command Recall and Continuity v1

## Default

Realistic Continuity is the default.

When the commander leaves the Command Deck:

- expedition time continues;
- deterministic crew handles routine work;
- reversible advisory work can continue;
- notifications accumulate;
- irreversible command branches are held;
- command-level situations trigger a recall.

## Authority levels

### Routine

Crew resolves and logs the event.

### Advisory

Crew continues reversible work and notifies command.

### Command required

Crew chooses only a low-risk reversible holding posture, preserves the decision branch, and calls command back to the deck.

## Optional pause mode

Pause Away From Command freezes expedition progression while the player explores the interior. Personal navigation and reading time may still advance.

## Safety boundary

Deterministic crew autonomy does not silently authorize irreversible actions reserved for the selected command mode.
